# 路线图

本文件是规划意向，不构成发布时间承诺。优先级会随真实使用反馈调整，欢迎在 Issue 里投票和讨论。

## 近期（v0.2 方向）

- 夸克 Cookie 保活（已随 v0.2.0 落地）：响应 Set-Cookie 轮换值自动回写持久化，后台约每 24 小时低频验活续期，状态页可见上次保活结果
- 待验证项收口：分享深层子目录文件直存（V2）、建夹/改名接口（V3）在真实环境完成验证并固化结论
- 目标目录多级浏览（已随 v0.3.0 落地）：设置页目录浏览器可逐级进入子目录选电影/电视剧目录
- 搜索体验：候选卡片显示体积与文件数概览，死链自动顺延下一候选

## 中期（v0.3 方向）

- 追更订阅：订阅剧集后定时重搜，只转存新集并自动清洗改名，完成后可推送通知
- 驱动接口定版：把搜索源与网盘驱动的接口正式抽象，为新增网盘做准备

## 长期探索

- 新增网盘驱动（百度网盘、阿里云盘、115 等），按驱动逐个接入
- 元数据补全（已随 v0.4.0 落地为找资源前的条目检索）：输片名先查 TMDB/豆瓣条目（海报、年份、评分、简介），选中再找资源；候选卡片本身的信息丰富仍在探索
- 多搜索源并行与结果合并

## 明确不做

- 播放、下载落盘、STRM 生成（定位是“搜 + 转存”，不做播放器和下载器）
- 多用户与权限系统（单用户自部署工具）
- 任何形式的凭证托管或中转服务
